# KHRPSC Website

A fresh static website starter for Karnataka Human Rights Public Service Committee.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Recommended: install the VS Code **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

You can also run a local server from this folder:
- Python: `python -m http.server 5500`
- Then open `http://localhost:5500`

## Stack
- HTML5, CSS3, vanilla JavaScript
- Three.js (CDN) for the animated justice-scale sculpture
- GSAP + ScrollTrigger (CDN) for motion and scroll reveals

## Important notes before production
- The donation form is **demo-only**. It does not process payments or store donor data.
- Connect a verified payment gateway (such as Razorpay) on a secure backend before accepting donations.
- Confirm the organization's registration, bank/merchant details, tax-exemption eligibility, privacy policy and donation receipt requirements before publishing claims.
- Replace illustrative stock photos with approved, consented photographs from actual KHRPSC programs. Do not present stock imagery as real committee activities.
- Any impact counts or case numbers must be based on records. No unverified statistics are included in this build.
- Social media URLs can be added when the client supplies official accounts.
- External fonts, Three.js, GSAP and photo URLs require an internet connection.
